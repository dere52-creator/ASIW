VLC — медиаплеер

VLC Media Player

VLC — бесплатный медиаплеер, который открывает почти все форматы видео и музыки. Не требует установки кодеков, работает быстро и без рекламы.

App Store

Установка на Linux (Ubuntu / Debian)

Открой терминал и введи:

sudo apt update
sudo apt install vlc

Установка на Linux (Fedora)

sudo dnf install vlc

Зачем скачивать?

  • Открывает все форматы: MP4, AVI, MKV, MP3, FLAC.
  • Без рекламы и без вирусов.
  • Работает быстро даже на старых компьютерах.
  • Бесплатный навсегда.
